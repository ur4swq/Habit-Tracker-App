# Habit Tracker

Bu repository Habit Tracker projesinin ana GitHub reposudur.

## Amaç

Habit oluşturma ve silme, streak takibi, mood takibi ve ilgili arayüz özelliklerini tek bir düzenli proje altında geliştirmek.

## Çalışma düzeni

- Çalışan sürümü bozacak büyük değişiklikleri doğrudan tek seferde yapma.
- Her anlamlı özellik veya düzeltme için ayrı ve açıklayıcı commit kullan.
- API key, token, parola veya secret dosyalarını repoya ekleme.
- Gerekli `.gitignore` dosyasını kullanılan teknolojiye göre güncel tut.
- Büyük özelliklerde mümkünse ayrı branch / pull request kullan.

## Önerilen commit örnekleri

- `chore: initial project setup`
- `feat: add habit management`
- `feat: add streak tracking`
- `feat: add mood tracking`
- `fix: correct mood localization`
- `fix: resolve download and open issue`
- `refactor: clean up project structure`
